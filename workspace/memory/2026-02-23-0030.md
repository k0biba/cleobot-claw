### So geht's:

**1. Neuen Agent erstellen:**
```bash
openclaw agents add emotional-checkin
```

Das erstellt einen eigenen Workspace unter `~/.openclaw/workspace-emotional-checkin` mit eigener `SOUL.md`, `IDENTITY.md`, etc.

**2. Persona definieren:**
Dann die `SOUL.md` und `IDENTITY.md` im neuen Workspace anpassen – z.B. empathisch, warmherzig, für Check-ins optimiert.

**3. Routing einrichten:**
In `~/.openclaw/openclaw.json` ein Binding hinzufügen:

```json5
bindings: [
  { agentId: "emotional-checkin", match: { channel: "telegram", accountId: "default" } },
  { agentId: "main", match: { channel: "telegram" } }, // fallback
]
```

**4. Gateway neustarten:**
```bash
openclaw gateway restart
```
